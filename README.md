# Prueba Evaluacion 2 - Sistema de Geolocalización

Este proyecto forma parte de la Evaluación 2. 

Consiste en un script de Python que consume la API REST de GraphHopper para planificar viajes y generar la ruta de viaje junto a las instrucciones optimizadas del mapa.

## Requisitos
- Utilización de Python
- Utilización de Biblioteca "requests"

## Otros

- Algunos detalles deben ser ingresados en ingles pero cada salida es en español.
- Se indica por km y minutos, en ves de millas
